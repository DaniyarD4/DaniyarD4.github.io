# Портфолио — Данияр Нурсалимов

Одностраничный сайт-портфолио разработчика программного обеспечения. Четырнадцать проектов на вертикальной «дороге»: описание, использованные технологии и приложенные материалы — отчёты в PDF, схемы, скриншоты и видеодемонстрации.

**Живая версия:** https://daniyard4.github.io

---

## Стек

Чистые HTML, CSS и JavaScript. Без сборщика, без фреймворков, без внешних зависимостей кроме шрифтов Google Fonts. Весь сайт — один файл `index.html`, поэтому правится в любом редакторе и открывается двойным кликом.

- Адаптивная вёрстка от 320px
- Заставка на весь экран с автоматическим растворением
- Просмотр PDF во встроенном окне без перехода на другую страницу
- Появление блоков при прокрутке через IntersectionObserver
- Поддержка `prefers-reduced-motion`
- Семантическая разметка, ARIA-атрибуты, навигация с клавиатуры

## Запуск локально

Никакой сборки не нужно — достаточно открыть `index.html` в браузере.

Если нужен локальный сервер (например, чтобы корректно работали абсолютные пути):

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Публикация

### Netlify

1. Зайти на [app.netlify.com/drop](https://app.netlify.com/drop)
2. Перетащить папку проекта целиком
3. Сайт публикуется за несколько секунд

Конфигурация `netlify.toml` подхватится автоматически.

### Vercel

```bash
npx vercel --prod
```

### GitHub Pages

1. Создать репозиторий и загрузить файлы
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`

## Как добавить проект

Открыть `index.html`, найти массив `PROJECTS` и добавить объект:

```javascript
{
  km: "210 KM",
  title: "Название проекта",
  desc: "Короткое описание, видно всегда.",
  tags: ["Технология", "Технология"],
  details: "Подробный текст, открывается по кнопке «Подробнее».",
  attachments: [
    { type: "image", src: "files/папка/скриншот.jpg", label: "Подпись" },
    { type: "pdf",   src: "files/папка/отчёт.pdf",    label: "Отчёт.pdf" },
    { type: "video", src: "files/папка/демо.mp4",     label: "Демонстрация" },
    { type: "file",  src: "files/папка/данные.xlsx",  label: "Таблица.xlsx" }
  ]
}
```

Порядок объектов в массиве определяет порядок карточек на дороге. Флаг `featured: true` выделяет карточку акцентом.

## Настройка оформления

Все цвета, отступы и скругления собраны в блоке `:root` в начале `index.html`. Время показа заставки задаётся дважды и должно совпадать: переменная `--splash-time` в стилях и константа `SPLASH_TIME` в скрипте.
