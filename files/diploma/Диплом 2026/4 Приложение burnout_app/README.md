# БВТ — Экспертная система мониторинга эмоционального выгорания тьюторов

## Зависимости
- Python 3.10+
- Flask >= 3.0
- Werkzeug >= 3.0

## Установка и запуск

```bash
pip install flask werkzeug
python app.py
# → http://127.0.0.1:5000
```

## Структура проекта

```
burnout_app/
├── app.py                  # Точка входа, create_app()
├── db.py                   # SQLite без ORM
├── auth_utils.py           # Аутентификация через session
├── engine/
│   ├── inference.py        # Продукционная экспертная система (41 правило)
│   └── questions.py        # Вопросы MBI (22) + CBI (19)
├── knowledge_base/
│   └── rules.json          # База знаний: правила IF-THEN
├── routes/
│   ├── auth.py             # Вход/регистрация/выход
│   ├── tutor.py            # Дашборд, опрос, результаты
│   └── hr.py               # HR: сотрудники, аналитика
├── templates/              # Jinja2 шаблоны
└── static/
    ├── css/main.css
    └── js/main.js
```

## Научная основа

- **MBI** — Маслач-Джексон (адаптация Водопьяновой–Старченковой, 2008)
- **CBI** — Копенгагенский опросник (адаптация Шайгеровой и др., 2025)
- **6 субшкал**: EE, DP, PA (MBI) + PB, WB, CB (CBI)
- **41 продукционное правило** IF-THEN с прямым выводом
